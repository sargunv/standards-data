# Currency Codes

Data from [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) - standardized
three-letter codes for currencies worldwide.

## Files

- [current.csv](./current.csv) - Active currency codes with alphabetic code,
  numeric code, minor units (decimal places), and the countries using each
  currency.
- [historical.csv](./historical.csv) - Withdrawn currency codes with withdrawal
  dates, tracking currency changes like Euro adoption or national currency
  replacements.
