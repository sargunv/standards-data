# Standards Data

Machine-readable datasets for commonly-used international standards. This
repository collects data from standards organizations in CSV format for ease of
integration into applications.

## Datasets

- [country-codes](./country-codes/) - ISO 3166 country and territory codes
- [currency-codes](./currency-codes/) - ISO 4217 currency codes
- [language-codes](./language-codes/) - ISO 639 language codes
