# Language Codes

Data from [ISO 639](https://en.wikipedia.org/wiki/ISO_639) - comprehensive codes
for language identification covering thousands of languages.

## Files

- [language-codes.csv](./language-codes.csv) - Complete language code registry
  with 2-letter (Part 1), 3-letter bibliographic/terminology (Part 2), and scope
  indicators for all languages.
- [language-names.csv](./language-names.csv) - Reference names for each language
  code in both inverted and print-friendly formats for easy display.
- [deprecated-code-mappings.csv](./deprecated-code-mappings.csv) - Retired
  language codes mapped to their replacements, with retirement dates and reasons
  (merger, split, or non-existence).
- [macrolanguage-mappings.csv](./macrolanguage-mappings.csv) - Individual
  language variants grouped under broader macrolanguage categories (e.g., Arabic
  dialects under 'ara').
