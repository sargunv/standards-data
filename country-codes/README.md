# Country Codes

Data from [ISO 3166-1](https://en.wikipedia.org/wiki/ISO_3166-1) -
internationally recognized codes for countries, territories, and special areas.

## Files

- [country-codes.csv](./country-codes.csv) - Current ISO 3166-1 country codes
  with alpha-2, alpha-3, and numeric identifiers for all countries and
  territories.
- [formerly-used-country-codes.csv](./formerly-used-country-codes.csv) -
  Historical country codes that are no longer assigned, including their validity
  dates and what replaced them.
- [reserved/exceptionally-reserved.csv](./reserved/exceptionally-reserved.csv) -
  Codes reserved for specific organizations like UPU, ITU, and WCO (e.g., AC for
  Ascension Island, EU for European Union).
- [reserved/indeterminately-reserved.csv](./reserved/indeterminately-reserved.csv) -
  Codes reserved indefinitely for organizations like WIPO or for vehicle
  distinguishing signs.
- [reserved/transitionally-reserved.csv](./reserved/transitionally-reserved.csv) -
  Former country codes reserved for 50 years after retirement to prevent
  accidental reuse (e.g., YU for Yugoslavia).
